# PULSE OGP Images

## 必要な画像

### ogp.png (メイン)
- サイズ: 1200x630px
- 内容: PULSEロゴ + グラデーション背景
- 色: #0a0a0f (背景) + #00f5d4 → #7b2cbf (グラデーション)

### 個別ページ用 (オプション)
各コンテンツ専用のOGP画像を作る場合:
- ogp-sand.png
- ogp-sort.png
- ogp-typing.png
- 等
